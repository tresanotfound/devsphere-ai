# DevSphere_AI

DevSphere_AI is an AI-powered developer productivity platform designed to streamline modern software development workflows through intelligent automation, centralized collaboration, and scalable engineering utilities.

The platform combines AI-assisted development tools, workflow management, backend services, and frontend utilities into a unified ecosystem that improves developer efficiency and project coordination.

---

## Overview

DevSphere_AI is built to reduce fragmentation in development environments by integrating multiple engineering workflows into a centralized platform.

The project architecture follows a modular full-stack approach with separate frontend and backend services for scalability, maintainability, and deployment flexibility.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/DevSphere_AI.git
cd DevSphere_AI
```

---

## Installation

### Install Frontend Dependencies

```bash
cd frontend
npm install
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

---

## Running the Application

### Start Backend

```bash
cd backend
npm run dev
```

### Start Frontend

```bash
cd frontend
npm run dev
```
