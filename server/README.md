# DevSphere AI Backend 🚀

Backend server for DevSphere AI — an AI-powered productivity and collaboration platform.

## Features

- JWT Authentication
- Role-Based Access
- AI Workspace APIs
- Realtime Chat
- Notifications
- Analytics
- Socket.io Integration
- File Uploads
- MongoDB Integration

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.io
- JWT
- Multer

## Run Backend

```bash
npm install
npm run dev
